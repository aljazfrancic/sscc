# SSCC label check

[![CI](https://github.com/aljazfrancic/sscc/actions/workflows/ci.yml/badge.svg)](https://github.com/aljazfrancic/sscc/actions/workflows/ci.yml)

A C++17 console program that checks scanned GS1-128 SSCC labels of TSX GmbH and explains exactly what is wrong with each label. The task is in [instructions.md](instructions.md), and the plan and its decisions are in [plan.md](plan.md).
